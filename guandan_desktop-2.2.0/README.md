# 掼蛋俱乐部 Desktop 2.2

Desktop 2.2 重点重做了联机大厅、牌桌布局和高难度 AI。保持无需第三方登录、局域网直连、自建公网服务器和完整贡还升级规则。

## 2.2 新增 / 调整

- 联机大厅拆分为 **局域网 / 公网** 两种模式。
- 四个牌位改为可点击自选座位，1/3 为一队、2/4 为一队。
- 新增 **2 个替补/观战位**。牌局中真人离开后，AI 会立即接管；替补可点击空位补入继续打。
- 新增 **准备 / 取消准备**；房主只有在已入座真人全部准备后才能开局。
- 新增 **房主踢人**。
- 新增 **断线重连**：客户端保存重连令牌和上次服务器地址；断线后可快速重连。原座位仍空闲时会优先恢复，若已被替补占用则回到观战席。
- 新增房间聊天；聊天与出牌记录同在“牌局动态 · 聊天”区域。
- 联机昵称增加《凡人修仙传》角色名推荐，可一键换名，也可自由修改。
- AI 难度选择收进牌桌右上角，不再占用整块侧栏。
- 主页面固定在一个窗口内，**页面本身不再上下滚动**；牌局动态区域独立滚动。
- 手牌改成最多 14 张一行、自动两行显示。
- 新增 **手动排序 / 自动排序**。手动排序开启后可拖动牌改变位置。
- 新增发牌/出牌动效、当前行动玩家呼吸高亮、胜负结算动画。
- 新增合成式出牌/不出/聊天/结算音效，不依赖额外音频文件，可在顶部关闭。
- “地狱 AI”升级为：公开出牌记牌统计 + 牌权评估 + 对手报单/报双防守 + 队友送牌/推牌 + 残局两步牌形推演。
- 地狱 AI **不读取其他玩家暗牌内容**；测试中交换对手暗牌而保持公开信息不变，决策保持一致。

## 联机人数与替补

一个房间最多：

- 4 名牌手；
- 2 名替补/观战玩家。

不足 4 名真人时，空牌位由 AI 控制。对局过程中真人掉线/离开后，该位置立即由 AI 接管；替补可以从联机大厅点击空位补上。

## Windows EXE：电脑无需安装开发软件

如果仓库根目录就是本工程：

1. 上传工程到 GitHub。
2. Actions → **Build Windows EXE** → **Run workflow**。
3. 等待绿色成功标记。
4. 在 Artifacts 下载 `Guandan-Club-Windows`。
5. 解压后得到 `Guandan-Club-Setup-2.2.0.exe`。

如果你像当前仓库一样把工程放在 `guandan_desktop/` 子文件夹，请保留仓库根目录现有的 Actions 工作流，并让其 `working-directory` 指向 `guandan_desktop`。

## 局域网联机

房主：联机大厅 → **局域网** → 创建并进入。默认：

- WebSocket/TCP：37821
- UDP 自动发现：37822

同一路由器/Wi-Fi 可自动发现，也可手动连接：

```text
ws://房主局域网IP:37821
```

Windows 防火墙首次提示时允许“专用网络”。

## 公网联机

在可公网访问的 Windows/Linux/VPS 上：

```bash
npm install
npm run server
```

开放 TCP 37821，客户端在联机大厅切换到 **公网** 后输入：

```text
ws://服务器公网IP:37821
```

使用 HTTPS 反向代理时可使用 `wss://域名`。该方案不依赖 Firebase、Supabase 或第三方账号登录。

## AI 六档难度

- 入门：随机合法出牌，尽量避免无意义炸弹。
- 新手：基础牌型效率，保留较明显随机误差。
- 普通：拆牌、剩余张数、炸弹保存。
- 困难：多步牌形与残局压力。
- 专业：公开记牌、队友协同、牌权控制。
- 地狱：更完整的公开记牌模型、推牌、报单防守和残局两步推演。

所有 AI 默认离线运行，不需要 API Key，也不需要外网。
