# 掼蛋俱乐部 Desktop 2.3.1

Desktop 2.3.1 继续保留 2.2 的完整贡还升级、六档 AI、自选座位、替补观战、聊天、踢人和重连，并重点重做联机入口与牌桌操作。

## 2.3.1 联机修复

- 修复有 VPN、Hyper-V、VMware、WSL 等虚拟网卡时，局域网房间码可能写入错误 IP 的问题。
- 局域网加入房间时：先自动发现；发现不到会自动扫描当前局域网并按房间码验证房主，不再只死连房间码中的单个 IP。
- 局域网房主同时发送 UDP 组播和广播，提高家用路由器下的发现成功率。
- 公网建房会尝试通过 UPnP 自动建立 TCP 端口映射。路由器不支持 UPnP 时会明确提示手动映射。
- 连接失败时保留真实原因，不再一律被“连接已断开”覆盖。
- 修复 AI 在极端牌型/边界状态下偶发不出牌的问题：每次 AI 行动都会校验结果，失败时重新生成合法牌，并加入自动恢复看门狗。
- 注意：如果运营商使用 CGNAT，没有真正的公网 IPv4，房主电脑无法仅靠房间码直接作为公网服务器；这种情况必须使用中继/VPS/内网穿透方案。

## 2.3 主要更新

- **局域网 / 公网都改为房间码加入**：房主创建房间后生成房间码，其他玩家只输入房间码即可加入，不再要求输入 `ws://IP:端口` 或域名。
- **公网模式由房主电脑直接作为服务器**：程序自动识别公网 IPv4，把公网 IP + 端口编码进房间码；加入方自动解析并连接。
- **局域网房间码同样可直接解析**；同一局域网的自动发现仍保留，用于优先找到实际房主网卡地址。
- 新增 **退出联机房间**。
- 新增 **联机重新开局**：房主可在对局中直接重开，所有玩家保留在当前房间。
- 手牌改为更接近真实打牌的 **轻微重叠式两排布局**。
- 新增 **一键摆牌**：自动识别并集中摆放同花顺、炸弹、钢板、三连对、三带二、顺子、三张、对子等组合，之后仍可手动拖动调整。
- 新增 **右键出牌**：右键未选中的单牌可快速尝试出牌；已选中多张时，右键任意已选牌可直接出整组。
- 各家打出的牌不再全部堆在牌桌正中央，而是显示在 **各自座位门前**。
- 其他玩家的剩余张数在 **10 张及以下** 时才显示；出完后显示“已出完”。

## 房间码规则

房间码分两类：

- `L...`：局域网房间码；
- `P...`：公网房间码。

房间码内部包含连接所需的 IPv4 与端口，并带校验码。界面会自动加短横线方便抄写，输入时是否带短横线都可以。

### 局域网

1. 所有电脑连接同一个 Wi-Fi / 路由器。
2. 房主：联机大厅 → **局域网** → 创建房间。
3. 程序生成以 `L` 开头的房间码。
4. 其他玩家：局域网 → 输入房间码 → 加入。
5. Windows 防火墙首次提示时请允许“专用网络”。

默认端口：

- WebSocket/TCP：`37821`
- UDP 自动发现：`37822`

### 公网

1. 房主：联机大厅 → **公网** → “用这台电脑创建公网房间”。
2. 程序自动识别公网 IPv4，启动本机 WebSocket 服务器，并生成以 `P` 开头的房间码。
3. 朋友只输入该房间码即可连接，不需要知道 IP 或域名。

注意：房间码只是把连接信息变得更方便，并不能绕过家庭路由器或运营商 NAT。房主网络需要能从公网访问 TCP `37821`。如果路由器没有自动/手动端口映射，或宽带处于运营商 CGNAT 下，公网直连会失败；这种情况应改用具备公网 IPv4 的网络或后续增加中继服务器方案。

## 联机房间

- 4 个牌位，1/3 为一队，2/4 为一队；
- 最多 2 个替补/观战位；
- 玩家掉线后 AI 立即接管；替补可补入空位；
- 房间准备 / 取消准备；
- 房主踢人；
- 断线重连；
- 退出房间；
- 房主重新开局；
- 房间聊天。

## 手牌操作

- **自动排序**：按常规牌序整理。
- **手动排序**：开启后拖动牌改变位置。
- **一键摆牌**：优先把高价值组合集中摆在一起，再排列剩余牌。
- **右键出牌**：用于快速出牌；正常左键选择 + Enter / “出牌”按钮仍然保留。
