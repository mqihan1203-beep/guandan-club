# 掼蛋俱乐部 Desktop 2.1

这是“掼蛋俱乐部 / GUANDAN CLUB”桌面工程的规则补全版。它保留 Windows Electron、局域网联机、自建公网服务器和六档离线 AI，并把多局制掼蛋最关键的赛制流程接完整。

## 2.1 新增 / 修正

- 头游、二游、三游、末游完整结算。
- 双下：头游与搭档包揽前两名时升 3 级。
- 头游 + 三游升 2 级；头游 + 末游升 1 级。
- 双方分别保存自己的级数；每局由上局获胜方按自己的新级数作为本局级牌。
- 单贡、双贡、贡牌大小排序与贡牌转移。
- 红桃级牌（逢人配）不作为贡牌。
- 单贡抗贡：进贡者有两张大王时抗贡。
- 双贡抗贡：进贡方两人合计有两张大王时抗贡。
- 真人受贡后可自己选择还贡牌；AI 受贡会自动选择。
- 还贡默认限制为牌点不高于 10；极端无合法牌时带流程兜底，防止牌局锁死。
- 正常贡还完成后，由“进贡给头游”的玩家领出；抗贡后由上局头游领出。
- 接风 / 借风：玩家最后一手出完且其余在场玩家都不压时，由其对家领出下一圈。
- A 级必打：在 A 级取得头游且搭档为二游或三游才算成功过 A；头游 + 末游仍留在 A。
- 修正炸弹顺序为：四炸 < 五炸 < 同花顺 < 六炸 < 七炸 < 八炸 < 四王炸。
- 联机服务器同步支持贡牌、还贡、下一局和整场过 A。
- 六档人机继续保留：入门 / 新手 / 普通 / 困难 / 专业 / 地狱。

> 掼蛋在地方娱乐局和不同赛事中存在少量细则差异。Desktop 2.1 默认采用常见竞技/娱乐口径，重点保证整套流程可连续运行。后续若要严格复刻某一项具体赛事，可以再加“规则预设”。

## Windows EXE：电脑无需安装开发软件

1. 把整个工程上传到 GitHub 仓库。
2. 打开 **Actions** → **Build Windows EXE** → **Run workflow**。
3. GitHub 的 Windows 机器会安装依赖并自动打包。
4. 在工作流的 Artifacts 中下载 `Guandan-Club-Windows`。
5. 里面生成 `Guandan-Club-Setup-2.1.0.exe`。

## 局域网联机

房主打开“联机大厅” → “创建房间”。默认：

- TCP / WebSocket：37821
- UDP 局域网发现：37822

同一 Wi‑Fi / 路由器下的电脑可自动发现，也可输入：

```text
ws://房主局域网IP:37821
```

Windows 防火墙首次询问时允许“专用网络”。

## 公网联机

在一台可公网访问的 Windows / Linux / VPS 上：

```bash
npm install
npm run server
```

开放 TCP 37821 后，客户端连接：

```text
ws://服务器公网IP:37821
```

如果使用 HTTPS 反向代理，可改为 `wss://`。联机不依赖第三方账号登录、Firebase、Supabase 或必须使用 VPN 的服务。

## AI

- 入门：随机合法牌，尽量少炸。
- 新手：基础牌型选择，保留一定随机误差。
- 普通：考虑拆牌效率、剩余张数和炸弹保存。
- 困难：增加多步牌形评估与临近走完防守。
- 专业：强化队友让牌、牌权和残局评估。
- 地狱：更深候选评估与残局搜索。

AI 默认离线运行，不需要 API Key，不依赖外网。贡还牌阶段 AI 也会根据当前手牌结构选择还贡牌。
